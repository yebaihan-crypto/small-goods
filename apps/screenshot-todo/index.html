应用核心特色

🚀

极速截图触发

无需繁琐的导出分享。通过 iOS 的「背面轻点」或「操作按钮」一键运行快捷指令，自动获取相册最新截屏并静默调起 App 自动处理。

🧠

本地智能 OCR 解析

调用苹果官方 Vision 框架。在设备本地安全识别图片中的文字和二维码。采用本地规则解析器，秒级自动抓取任务截止时间，保护数据绝对安全。

🔔

系统级原生同步

使用 EventKit API 深度同步系统「提醒事项 (Reminders)」。您通过截屏生成的待办任务可直接显示在苹果官方日程中，更支持跨设备云同步。

📱

锁屏实时活动

借由 ActivityKit 支持，任务进度将在您的 iOS 锁定屏幕及灵动岛（Live Activity）中直观呈现，并自动带有截图缩略图，抬手即可概览进度。

快捷指令配置指引

iOS 系统原生不提供“完成截图后静默执行”的触发器。因此，App 采用快捷指令作为执行入口。您仅需 3 分钟即可完成配置。

1

新建快捷指令

打开系统自带的 「快捷指令 (Shortcuts)」 应用，点击右上角的 「+」 新建，将其命名为 截图即待办。

2

获取最新照片截图

在快捷指令中添加一个操作：「查找照片」，并在过滤器中进行如下配置限制，以准确获取刚刚生成的最新截图：

■ 媒体类型 是 图像 ■ 相簿 是 截屏 ■ 排序方式 选择“创建日期”，顺序为“最新优先” ■ 限制 开启，并设置仅获取 1 张照片
3

调用 App 意图处理

添加下一个操作，搜索并添加本 App 的 「处理截图待办 (Process Screenshot Todo)」 操作：

将上一步「查找照片」所输出的 照片 传入作为 截图 参数。

4

绑定极速触发按键

推荐将该快捷指令绑定在系统级物理触发入口，享受一键截图后立刻生成待办的爽快体验：

  • 轻点背面：前往「系统设置 > 辅助功能 > 触控 > 轻点背面」，在轻点两下或三下中，下拉选择刚刚创建的快捷指令 截图即待办。
  • 操作按钮 (Action Button)：前往「系统设置 > 操作按钮」，左右滑动选择「快捷指令」，指定为 截图即待办。

Shortcuts Setup Guide

Set up in just 3 minutes to turn screenshots into actionable tasks effortlessly.

1

Create a New Shortcut

Open the native Shortcuts app on iOS, tap "+" to create a new shortcut, and name it ScreenshotTodo.

2

Get Latest Screenshot

Add action: "Find Photos", and configure filters to retrieve the latest screenshot:

■ Media Type is Image ■ Album is Screenshots ■ Sort by "Date Taken", Order "Latest First" ■ Limit to 1 Photo
3

Process Screenshot

Add action: "Process Screenshot Todo" from this app, and pass the photo output from Step 2 as the Screenshot parameter.

4

Bind Physical Trigger

Assign the shortcut to a physical trigger for instant task creation:

  • Back Tap: Settings > Accessibility > Touch > Back Tap, assign to ScreenshotTodo.
  • Action Button: Settings > Action Button, select Shortcut > ScreenshotTodo.
