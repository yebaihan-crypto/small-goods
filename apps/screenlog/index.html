关于这个应用About

时间轴上的每个节点是一次打开，两个节点之间的线长就是这一次持续了多久，颜色跟着那个 App 的主题色走。常驻锁屏实时活动，不用打开应用也能看见今天怎么过的。Each node on the timeline is one launch; the length of the line between two nodes is how long that session lasted, coloured by that app's own theme. A permanent Live Activity means you can see how the day went without opening anything.

主要功能Highlights

  • 行为时间轴（线长 ＝ 时长）Behaviour timeline (line length = duration)
  • 锁屏实时活动常驻Permanent Lock Screen Live Activity
  • 会话闭合算法Session-closing algorithm
  • 按 App 主题色区分Coloured by each app's theme
